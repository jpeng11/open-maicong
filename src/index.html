      100% Offline Architecture
      
          
      Unlike the vendor web configurator which requires online cloud bundles, telemetry, and WebHID browser tabs, Maicong Studio is built from the ground up as a native macOS utility:
      
          
        
            
      • Zero Remote Network Requests: Content Security Policy strictly enforces connect-src 'none'. No analytics, tracking, or remote JS.
        • 
            
      • Pure Native Node-HID: Direct connection to macOS IOKit USB HID endpoints via node-hid.
        • 
            
      • Serialized I/O & Nonexclusive Safety: All packets are single-flight sequenced with timeouts. Normal typing is never locked out.
        • 
            
      • Writes: Lighting and Key Config onboard edits save automatically. Custom profile preview stays on this Mac (zero HID). Activate, profile enable, and factory reset still require an explicit click. Live device writes have been mock-tested only. Physical factory reset has not been tested.
